KintaiApp

React Native(Expo)で開発した勤怠管理アプリです。

概要

出退勤の記録・管理をスマートフォンから行えるアプリです。個人開発として、Claude Codeと連携しながら開発を進めています。

技術スタック
React Native
Expo
TypeScript
開発
bash
npm install
npx expo start

Expo Goアプリ、またはシミュレーター/エミュレーターで動作確認できます。

ディレクトリ構成
.
├── src/            # アプリ本体のコード(画面・コンポーネントなど)
├── assets/         # 画像・アイコンなどの素材
├── scripts/        # 補助スクリプト
├── app.json        # Expoの設定(アプリ名・アイコンなど)
└── CLAUDE.md / AGENTS.md  # AIエージェント向けの開発方針・手順
